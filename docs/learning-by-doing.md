# 从一次实验写一条用得上的笔记

没有研究证明某种文件夹布局最适合所有人。这里要解决的是更具体的问题：隔几天回到一个陌生训练故障时，能不能复现现象、解释原因，再用不同输入检验解释。目录按系统归档，学习按任务前进；两者不必长成同一棵树。

## 这条路线依据什么

| 依据 | 能支持什么 | 在本库怎样用 |
| --- | --- | --- |
| [Sweller 与 Cooper：代数学习中的完整例题](https://doi.org/10.1207/s1532690xci0201_3) | 在他们研究的初学代数任务中，学习已解示例有利于解决相似问题；并非所有复杂系统都能靠照抄学会 | 第一次给一个可运行的完整例子和几个关键读数；第二次只换一个输入，先预测，不给一串新命令去背 |
| [Karpicke 与 Blunt：主动提取与概念图](https://pubmed.ncbi.nlm.nih.gov/21252317/) | 在科学文本学习实验中，主动重建知识有利于之后的理解与推断。研究没有比较 Obsidian 目录 | 合上笔记，重画一次 rank 布局或解释一个误差；再展开答案或对照输出。知识地图用于找路，不当作已学会的证据 |
| [Cepeda 等：复习间隔与保持时间](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf) | 适宜的复习间隔与想保持多久有关，不存在适合所有材料的固定天数 | 下一次学习先做上次的变式；之后隔开再做一次。能解释就换情境，解释不出来就回原实验 |
| [Diátaxis：教程](https://diataxis.fr/tutorials/) | 这是文档设计框架，不是认知实验：带人做成一件事与解释机制是两种需求 | 实验目录放代码、输入和判据；数学推导、组件职责、源码证据留在同一子系统的独立笔记里，通过链接相遇 |

## 一条真的记录长什么样

**现象**：训练从第 5 步恢复，第一条样本对了，最终权重却不同。

**对照**：固定四条样本，完整恢复与漏动量两组都从样本 1 开始；完整恢复的权重误差为 0，漏动量约 0.224。

**结论**：数据游标正确不足以证明优化器状态恢复正确。

**下次变式**：在第 4 步中断，再用同一方法判断只检查样本顺序会漏掉什么。运行入口：[断点回放](../ai/training/checkpoint-replay/README.md)。

自己的记录只保留：输入与环境、预测、改变的一个条件、实际输出、结论边界、下次变式。不要把日志里的机器名和凭据贴进公共笔记，也不必给每个实验抄一遍定义。赶时间时，记下让你改变判断的那一行，比给整篇笔记划重点更有用。
