# 选一条 Kubernetes 实践路线

**目标是训练平台**：先做[调度与恢复](../../../ai/training/README.md)，交付一份作业从排队到第一步训练的记录。只有当一张物理卡要给不同工作负载共享时，再走 [HAMi 路线](../scheduling/hami-learning-path.md)。

**目标是自己开发控制器或插件**：走[Kubernetes 开发路线](k8s-development-roadmap.md)，从一次事件或一个设备开始，用[进度表](progress.md)记录实际看见的状态变化，不按读过的篇数打勾。

选 Demo 前查[环境与历史验证](k8s-lab-environments.md)。排查时不知道该找谁，用[组件地图](k8s-component-map.md)；已定位到具体组件，要跟函数调用才查[源码地图](k8s-source-map.md)。
